@startuml
title Реєстрація на курс

|Student|
start
:Обрати курс у каталозі;
:Надіслати заявку на реєстрацію; <<output>>

|Enrollment system|
if (Курс доступний?) then (ні)
  :Повідомити про недоступність курсу; <<output>>
  end
else (так)
  if (Студент вже зареєстрований?) then (так)
    :Повідомити про повторну реєстрацію; <<output>>
    end
  else (ні)
    if (Сума кредитів <= 30 ECTS?) then (ні)
      :Повідомити про перевищення ліміту; <<output>>
      end
    else (так)
      :Зберегти запис на курс;
      fork
        :Сформувати сповіщення про успішну реєстрацію; <<output>>
      fork again
        :Оновити кількість кредитів ECTS;
      fork again
        :Надіслати підтвердження на email; <<output>>
      end fork
    endif
  endif
endif

|Student|
:Отримано підтвердження реєстрації; <<input>>
:Переглянути курс у навчальному плані;
stop
@enduml
